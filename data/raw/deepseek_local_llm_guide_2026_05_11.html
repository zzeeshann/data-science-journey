The Function That Makes It Work

def ask_qwen(prompt, article_text):
    response = requests.post(
        "http://localhost:1234/v1/chat/completions",  # The order window
        json={
            "model": "qwen2.5-14b-instruct",  # Which chef to use
            "messages": [
                {"role": "system", "content": prompt},  # Instructions for the chef
                {"role": "user", "content": article_text}  # What to cook
            ],
            "temperature": 0.1  # How creative the chef should be
        }
    )
    return response.json()["choices"][0]["message"]["content"]  # The dish

Part 6: Key Concepts Explained Simply

What is a Dataset?

A dataset is just a big collection of examples. AG News has 120,000 rows, each with text (the news article) and label (0=World, 1=Sports, 2=Business, 3=Sci/Tech). Think of it like a giant spreadsheet where someone already filled in the correct answers.

What is a Model?

A model is a mathematical function trained on billions of examples. When you give it new text, it uses patterns it learned to predict things. Qwen has "14 billion parameters" — think of these as 14 billion knobs that were tuned during training to make it good at understanding language.

What is an API?

API = "Application Programming Interface." It's just a standard way for two programs to talk. When you call http://localhost:1234/v1/chat/completions, you're using LM Studio's API — the agreed-upon format for sending questions and getting answers.

What is Quantization (4-bit)?

A full AI model takes up a lot of space. Quantization compresses it by storing numbers with less precision — like saving a photo as a smaller JPEG instead of a huge RAW file. 4-bit quantization makes the model 4x smaller with only a tiny quality loss. That's how a 28GB model fits into 9GB and runs on your Mac.

Why Use a Virtual Environment?

Python projects need different versions of packages. A virtual environment creates an isolated bubble so your news project's packages don't conflict with other projects. Always use one.
