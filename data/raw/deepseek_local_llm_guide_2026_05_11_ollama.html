2. Complete System Setup (From Zero)

⚠️ Prerequisites: Mac with Apple Silicon (M1/M2/M3/M4), 16GB+ RAM recommended, macOS up to date.

Step 1: Install Ollama (Local AI Runtime)

# Download and install Ollama with one command
curl -fsSL https://ollama.com/install.sh | sh

# Verify it's installed
ollama --version

Step 2: Download the Qwen 2.5 14B Model

# Pull the 14B parameter Qwen model (9GB download)
ollama pull qwen2.5:14b

# Verify the model is downloaded
ollama list
# Should show: qwen2.5:14b
💡 Why this model? Qwen 2.5 14B is the "sweet spot" for 24GB Macs. Powerful enough for serious text analysis, small enough to run fast (28+ tokens/second). Larger models (32B+) won't fit comfortably in 24GB RAM.

Step 3: Set Up the Python Project

# Create project folder
mkdir ~/news-data-science
cd ~/news-data-science

# Create isolated Python environment
python3 -m venv venv
source venv/bin/activate

# Install all required packages
pip install datasets jupyter requests pandas matplotlib seaborn

Step 4: Start Jupyter Notebook

# Make sure venv is activated first
cd ~/news-data-science
source venv/bin/activate
jupyter notebook

Your browser opens at http://localhost:8888. Click New → Python 3 to create a notebook.

3. The Main Analysis Notebook

This is the complete notebook code for the project. Create a new notebook in Jupyter and run each cell.

📓 Cell 1: Import Libraries & Load Dataset

# ============================================
# AI NEWS ANALYZER - COMPLETE SETUP (OLLAMA)
# ============================================

from datasets import load_dataset
import requests
import pandas as pd
import time

# Load AG News dataset (downloads automatically first time)
dataset = load_dataset("ag_news")
categories = {0: "World", 1: "Sports", 2: "Business", 3: "Sci/Tech"}

print("✅ Dataset loaded! 120,000 training articles, 7,600 test articles.")
print(f"Categories: {categories}")
print(f"\nSample article:\n{dataset['train'][0]['text'][:300]}...")

📓 Cell 2: Create the Qwen Connection Function

# ============================================
# CONNECT TO LOCAL QWEN MODEL VIA OLLAMA
# ============================================

def ask_qwen(prompt, article_text):
    """
    Send an article to the local Qwen model and get analysis back.
    
    Parameters:
        prompt (str): Instructions telling Qwen what to do
        article_text (str): The news article text to analyze
    
    Returns:
        str: Qwen's response
    """
    response = requests.post(
        "http://localhost:11434/v1/chat/completions",  # Ollama API endpoint
        json={
            "model": "qwen2.5:14b",                     # Model name in Ollama
            "messages": [
                {
                    "role": "system", 
                    "content": prompt                    # Instructions
                },
                {
                    "role": "user", 
                    "content": article_text               # The article
                }
            ],
            "temperature": 0.1                           # Low = consistent answers
        }
    )
    return response.json()["choices"][0]["message"]["content"]

print("✅ ask_qwen() function ready!")

📓 Cell 3: Test the Connection

# ============================================
# TEST: Send one article to Qwen
# ============================================

test_article = dataset["train"][0]["text"]
true_label = categories[dataset["train"][0]["label"]]

result = ask_qwen(
    "Classify this news into ONE category: World, Sports, Business, or Sci/Tech. Return ONLY the category name.",
    test_article[:1000]  # Send first 1000 characters
)

print(f"Qwen predicted: {result.strip()}")
print(f"True label:     {true_label}")
print(f"Correct?        {result.strip().lower() == true_label.lower()}")

📓 Cell 4: Batch Process 50 Articles

# ============================================
# BATCH CLASSIFICATION: 50 Articles
# ============================================

results = []
num_to_process = 50

print(f"Processing {num_to_process} articles...")
for i in range(num_to_process):
    article = dataset["train"][i]
    true = categories[article["label"]]
    
    # Ask Qwen to classify
    pred = ask_qwen(
        "Classify this news into ONE category: World, Sports, Business, or Sci/Tech. Return ONLY the category name.",
        article["text"][:1000]
    ).strip()
    
    # Record result
    results.append({
        "article_id": i,
        "true_label": true,
        "qwen_prediction": pred,
        "correct": true.lower() == pred.lower()
    })
    
    # Progress update every 10 articles
    if i % 10 == 0:
        print(f"  Progress: {i}/{num_to_process}")
    time.sleep(0.1)  # Tiny delay to avoid overwhelming Ollama

# Calculate and display accuracy
df = pd.DataFrame(results)
accuracy = df["correct"].mean()

print(f"\n{'='*50}")
print(f"RESULTS")
print(f"{'='*50}")
print(f"Total articles:  {num_to_process}")
print(f"Correct:         {df['correct'].sum()}")
print(f"Wrong:           {num_to_process - df['correct'].sum()}")
print(f"Accuracy:        {accuracy:.1%}")
print(f"{'='*50}")

# Show the mistakes
mistakes = df[~df["correct"]]
if len(mistakes) > 0:
    print(f"\n❌ Mistakes ({len(mistakes)} articles):")
    for _, row in mistakes.iterrows():
        art = dataset["train"][int(row["article_id"])]
        print(f"\n  Article #{row['article_id']}:")
        print(f"  True label: {row['true_label']}")
        print(f"  Qwen said:  {row['qwen_prediction']}")
        print(f"  Text: {art['text'][:150]}...")

📓 Cell 5: Visualize Results (Confusion Matrix)

# ============================================
# VISUALIZATION: Confusion Matrix
# ============================================

import matplotlib.pyplot as plt
import seaborn as sns

# Create confusion matrix: true labels vs predicted labels
confusion = pd.crosstab(
    df["true_label"], 
    df["qwen_prediction"]
)

# Plot as heatmap
plt.figure(figsize=(8, 6))
sns.heatmap(confusion, annot=True, fmt="d", cmap="Blues", 
            xticklabels=["Business", "Sci/Tech", "Sports", "World"],
            yticklabels=["Business", "Sci/Tech", "Sports", "World"])
plt.title("Qwen Classification vs True Labels", fontsize=14)
plt.xlabel("Qwen Prediction")
plt.ylabel("True Label")
plt.tight_layout()
plt.show()

5. Key Concepts Explained Simply

What is a Dataset?

A dataset is a big collection of examples, like a spreadsheet. AG News has 120,000 rows. Each row has two columns: text (the news article) and label (the correct category: 0=World, 1=Sports, 2=Business, 3=Sci/Tech). Someone already labeled all 120,000 articles correctly — we use this to test if our AI can match human accuracy.

What is a Model?

A model is a mathematical function trained on billions of text examples. It learns patterns in language. Qwen has 14 billion parameters — think of these as 14 billion tiny knobs that were tuned during training. When you give it new text, it uses those learned patterns to predict, classify, summarize, or generate.

What is an API?

API = Application Programming Interface. It's a standard way for two programs to talk to each other. When your Python code calls http://localhost:11434/v1/chat/completions, it's using Ollama's API. The format is always the same: you send a request with instructions and text, you get back a response with the AI's answer.

What is localhost:11434?

localhost means "this computer." 11434 is a port number — like a specific door on your computer. Ollama listens at this door for requests. LM Studio used port 1234. Different apps use different ports so they don't conflict.

What is a Virtual Environment (venv)?

Python projects need specific versions of packages. A virtual environment creates an isolated bubble for your project. The packages you install inside venv won't conflict with other Python projects. Always use one. The command source venv/bin/activate enters the bubble; deactivate exits it.

What is Jupyter Notebook?

Jupyter is an interactive coding environment that runs in your browser. Instead of writing a whole script and running it once, you write code in small chunks called "cells." You run each cell individually and see results immediately. This makes it perfect for data exploration and learning.

What is the ask_qwen() Function?

This is the bridge between your notebook and the AI. You give it two things: a prompt (instructions like "classify this") and article_text (the actual news). It packages them into the format Ollama expects, sends them over localhost:11434, and returns whatever Qwen says. It's the single most important function in the whole project.

What Does 92% Accuracy Mean?

Out of 50 articles, Qwen correctly classified 46. That's 92% accuracy. The 4 mistakes (8%) are actually valuable — they show us where Qwen gets confused. Maybe it mixes up World and Business news. These patterns help us understand the model's strengths and weaknesses.
