# `ancient_voices/` — corpus folder, not a sub-investigation

A folder of verified passages from the oldest written texts, plus working notes from primary-source reading. Loaded by Sessions 8 onwards into the embedding pipeline alongside the modern corpus.

This is **not** a sub-investigation. There is no separate session log. No separate hypotheses. Work that uses these passages is logged in the parent `sessions/session_NN.md` files. The Wholeness Investigation's H3 — "the language of wholeness is rising in modern writing" — gets tested with a corpus that includes both modern and ancient texts. That's the whole story. No H5.

## Layout

```
ancient_voices/
├── README.md          ← this file
├── passages/          ← verified passages, one file per passage. Embedding inputs.
│   └── README.md      ← format spec for passage files
└── notes/             ← working notes from primary-source reading. Free-form. Not embedded.
```

## What's here, what isn't

**Here:** verified translations of specific passages with citation headers. Reading notes, sketches, partial extracts marked clearly as drafts. The reading guide at the project root (`ANCIENT_TEXTS_READING_GUIDE.md` — if kept; can move here later).

**Not here:** anything not yet verified against a primary source. Anything generated by an LLM without being checked. Speculations that haven't been tested. The book chapter that uses these passages (lives in `book/`). The session record that runs analysis on them (lives in `sessions/`).

## Verification standard

Inherits from `01_working_agreement.md` and the citation-grep rule in `CLAUDE.md`. Specifically:

1. Every passage file cites a primary source URL or a published academic translation.
2. Line numbers, spell numbers, law numbers, hexagram numbers — exact, not approximate.
3. Where a position is approximate (e.g. Descent of Inanna doesn't use conventional verse numbering), the file says so in its citation header.
4. Where a passage is fragmentary (e.g. Ugaritic KTU 1.12 is damaged), the citation header notes that and what the reconstruction is based on.

If a passage cannot meet this standard, it does not go in `passages/`. It can go in `notes/` as a working draft until verification is complete.
